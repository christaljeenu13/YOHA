# Yoha Landing Page

A responsive landing page developed for Yoha, showcasing modern design, clean UI, and optimized performance.  
This project demonstrates front-end development skills and deployment practices.

## Features
- Fully responsive design (mobile, tablet, desktop)
- Clean and modern UI
- Fast loading and optimized assets
- Easy to customize

## Tech Stack
- HTML5
- CSS3
- JavaScript
