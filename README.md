# Yoha Landing Page

This repository contains the landing page developed for **Yoha**.  
The project focuses on creating a responsive, modern, and user‑friendly interface that highlights the brand’s identity and provides a smooth browsing experience.

## Overview
The Yoha landing page was designed and built from scratch, following a structured workflow:
1. Planned the layout and content flow.
2. Designed a clean and responsive UI.
3. Implemented with HTML, CSS, and JavaScript.
4. Deployed the site using GitHub Pages.

## Features
- Responsive design for mobile, tablet, and desktop.
- Lightweight and fast loading.
- Organized project structure for easy maintenance.
- Deployed and accessible online via GitHub Pages.

## Tech Stack
- HTML5  
- CSS3  
- JavaScript
